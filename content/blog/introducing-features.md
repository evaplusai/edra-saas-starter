# Introducing New Features in Edra 1.0

We are excited to announce the release of Edra 1.0 with a host of new features designed to make building SaaS applications easier than ever.

## Role-Based Access Control

Edra now ships with a complete **RBAC** system. Assign roles to users and control access to every part of your application:

- **Admin** -- Full access to all features and user management
- **Member** -- Standard access to dashboard and settings
- **Viewer** -- Read-only access to shared resources

## API Key Management

Generate and manage API keys directly from the dashboard. Each key supports:

- Custom expiration dates
- Scoped permissions
- Usage tracking and rate limiting

## Subscription Management

Integrated **Stripe** billing lets your users manage their subscriptions with ease:

1. Choose a plan from the pricing page
2. Enter payment details securely via Stripe Checkout
3. Manage, upgrade, or cancel from the dashboard

## Analytics Dashboard

Track key metrics with the built-in analytics dashboard:

- **Page views** and **unique visitors**
- **User signups** over time
- **Revenue** and **churn** metrics

## What's Next

We have an exciting roadmap ahead, including:

- Team collaboration features
- Webhooks and integrations
- Advanced reporting

Stay tuned for more updates!
